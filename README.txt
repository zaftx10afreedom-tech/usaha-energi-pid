MODE PRESENTASI KELAS PID - USAHA DAN ENERGI
============================================

Versi ringkas dari pemutar Usaha dan Energi.

ISI
- 8 slide dari PPTX sumber (dirender sebagai gambar WebP)
- 12 kuis di dalam slide (PG dan pilihan ganda kompleks)
- Mode Presentasi Kelas aktif sejak halaman dibuka
- Navigasi geser satu jari, pena, laser, pembesaran dan layar penuh
- Rekap kuis lokal dan ekspor CSV

TIDAK DISERTAKAN
- Laboratorium virtual
- Menu simulasi dan kode perhitungan simulasi
- Mode pemutar biasa terpisah

MENJALANKAN
1. Ekstrak seluruh isi paket ke satu folder.
2. Buka index.html di Chrome/Edge. Jika file dibuka dari komputer,
   penggunaan penyimpanan hasil kuis dapat bergantung pada konfigurasi browser.
3. Pada hosting, unggah seluruh isi folder, termasuk direktori slides/.
4. Gunakan tombol ⛶ untuk layar penuh. Browser memerlukan interaksi pengguna.

GESTUR PID
- Geser satu jari ke kiri/kanan: slide selanjutnya/sebelumnya.
- Cubit dua jari: pembesaran.
- Saat diperbesar, geser slide untuk memindahkan tampilan.
- Pilih Pena untuk mencoret slide tanpa berpindah slide.
- Tombol Alat muncul kembali jika bilah alat otomatis tersembunyi.

CATATAN
Kuis disusun sebagai pelengkap PPTX; bukan bagian asli dari slide sumber.
Penskoran dikotomis. Hasil kuis tersimpan hanya di browser perangkat ini.
Untuk ribuan pengguna di berbagai perangkat, publikasi statis/CDN memungkinkan,
namun kinerja dan kompatibilitas perlu diuji di perangkat tujuan.

Materi PPTX asli tidak diedit. Terdapat salah ketik dalam materi asli
(pada bagian kekekalan energi mekanik) yang tidak diubah otomatis.
